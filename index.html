핵심 성과 · 승리 여부, 소요 턴, 본진 피해, 지휘 부대 이탈을 비교합니다. 소요 턴은 같은 전장·난이도 기준으로 해석합니다.

항목의미
result / turns승리 또는 패배 / 종료할 때까지 진행한 턴
first_capture_turn아군이 처음으로 거점을 점령한 턴. 초반 진군 속도 확인용
captured_at_end종료 시 아군이 보유한 9개 거점 수. 적 본진은 세지 않음
enemy_recapture_events적이 아군 점령 거점을 다시 빼앗은 횟수
hero_actions / hero_damage_dealt클리프 공격 횟수 / 실제로 깎은 적 HP 합계. 개입 효과를 확인할 때 사용
ally_artillery_shots / ally_artillery_damage_dealt아군 포격 횟수 / 실제로 깎은 적 HP 합계. 포격 효율 비교용
enemy_artillery_damage_dealt적 포격으로 아군 병력·거점이 실제로 잃은 HP 합계. 본진 직접 피해와 구분
rest_hp_recovered_total안전 지역 자동 회복으로 실제 되찾은 HP. 0이면 회복이 일어나지 않음
sourceui_controls는 화면 버튼 실행, automated_policy는 테스트 정책 실행. 전자는 사람이 플레이했다는 증거가 아님

주요 전황 · turn은 발생 턴, major_events는 점령·재탈환·측면 침투·본진 피해 등 사건의 종류입니다. base_damage_turn은 해당 턴에 본진이 받은 피해입니다. 일상적인 이동과 작은 HP 변화는 제외합니다.

핵심 설정 · parameter는 수치 이름, value는 적용 값, min/max는 허용 범위입니다. ally_attack은 아군 공격력, raider_attack은 제2·3전장의 침투병 공격력, enemyPeriod / enemyChallengePeriod는 각 난이도의 적 증원 주기입니다.

실험 비교 · 전략 비교: 전장·난이도·설정 ID(balance_config_id)를 같게 두고 지휘 방식만 바꿉니다. 수치 변경 비교: 전장·난이도·지휘 방식을 같게 두고 설정 ID가 다른 결과를 비교합니다. 이때 각 실험의 설정 CSV도 함께 보관하세요.
설정 변경 · 현재 선택한 전장·난이도로 핵심 설정을 내려받아 value만 수정하세요. 행을 삭제하거나 열 이름을 바꾸면 불러오지 못할 수 있습니다. 지휘 부대·클리프 HP 100은 고정입니다. 새로고침하면 누적 기록이 사라지므로 먼저 내보내세요.
출처 · session_id는 판마다 다른 식별자, engine_version은 게임 버전입니다. 모든 수치는 자체 시뮬레이터에서 나온 값으로, 실제 게임 이용자 통계가 아닙니다.
설정 불러오기 지휘 부대·클리프 HP 100
설정 CSV의 value 열만 수정하세요. 실험별 설정 ID는 결과 CSV에 기록됩니다.

새로고침하면 기록이 사라집니다. 종료 후 CSV를 저장하세요.

전황 기록 최신 순

전술 규칙
부대 명령진격: 경로상의 적과 교전하며 이동 · 우선이동: 공격하지 않고 이동을 우선하지만 공격받을 수 있음
거점 효과일반 거점: 병력 생산 · 요새 거점: 점령 세력 공격력 강화 · 병기 거점: 적 거점 포격 지원
전선·재출격직전 전선 거점 1곳을 점령해야 다음 전선으로 진입할 수 있습니다. 제3전선 전체 확보 후 적 본진 공략 가능. 전멸한 부대는 3턴 후 재출격합니다.
자동 회복·기록안전한 아군 지역에서 2턴 대기 후 자동 회복. CSV는 핵심 성과·주요 전황·핵심 설정 3종을 제공합니다.

기획서 기반 비공식 게임 시스템 검증용 프로토타입입니다. 전투 수치와 CSV는 자체 시뮬레이션 결과이며, 실제 붉은사막 플레이어 데이터가 아닙니다.
